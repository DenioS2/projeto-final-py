# Criador de GIF com Python

Este é um projeto simples em Python que automatiza a criação de imagens animadas (GIFs) a partir de imagens estáticas utilizando a biblioteca `ImageIO`.

## 🚀 Como Executar o Projeto

1. Instale a biblioteca necessária:
   ```bash
   pip install -r requirements.txt
   ```

2. Adicione as imagens que deseja juntar na mesma pasta do script com os nomes `team-pic1.png` e `team-pic2.png` (ou altere os nomes direto no código).

3. Execute o script:
   ```bash
   python create_gif.py
   ```

O arquivo `team.gif` será gerado automaticamente na mesma pasta.
